Generative Ambient Engine

a schema-driven parametric interface, not a preset menu

Every control below is read from GET /schema at load time and posted to POST /generate as a plain JSON body -- nothing here is hardcoded to today's parameter set on the server side. The scale/mode control, for instance, is not a fixed list of instrument presets: it exposes the actual maximal-evenness generator (cardinality + rotation coordinates) the engine now runs on, with the four classic named modes kept only as shorthand for specific coordinates. See ../README.md for the full parameter reference and this service's honestly-documented limits.

Quick start

These buttons only prefill the fields below from a named preset or mood bundle (see GET /presets) -- the actual request always sends the concrete parameter values shown in the form, never a preset name. What you see is what gets rendered.
