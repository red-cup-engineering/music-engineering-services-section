# Source note: `zen-soundscape-pine-in-snow.wav`

A single 8-minute render targeting the "zen ambient soundscape" YouTube genre
(nature-imagery titles, meditation/healing framing, guqin-coded timbre --
sparse texture, traditional-instrument-adjacent tone, slow harmonic
movement) rather than the engine's default continuous multi-voice pad wash.
Generated by `renderTrack()` (`src/generative/compose.mjs`), seed
`zen-soundscape-pine-in-snow-1`, `A` minor pentatonic, `deepAmbient` reverb.

## What changed from the engine's default output

Two additive changes made this possible without touching `renderTrack()`'s
default behavior (calling it with no new options renders byte-identical
output to before -- checked in `test/compose-sparse.test.mjs`):

- **Timbre**: two new named points in `dsp/oscillator.mjs`'s
  `generatePartials({count, rolloffExponent, oddEvenBias})` space --
  `breathyFlute` (steep rolloff, mostly-fundamental, used for the sustained
  pad bed) and `pluckedString` (brighter, fuller harmonic series, used for
  the foreground melodic line). Both are ordinary parameterizations of the
  existing generator, not a new preset mechanism.
- **Sparseness**: `renderTrack()` gained real optional controls over the
  actual generative mechanisms that produce density --
  `maxVoices` (cover.mjs's polyphony budget, set to 2 here vs. the default
  6), `baseInjectProb`/`risingInjectProb` (flow.mjs's per-tick pitch-class
  injection probability, cut roughly 7x), and
  `melodyPhraseGapSecMin`/`melodyPhraseGapSecMax` (widened to 22-45s vs. the
  default 4-9s). These are the same parameters the engine's own macro-form
  logic already reads -- this is not a hardcoded "make it sparse" pass
  applied after rendering.

## What was skipped, and why

The original scope for this piece also considered: a noise-excitation
breath/pluck transient, a background wind/water noise-texture layer, and
using the guqin corpus fixture's illustrative motif shape as melodic
inspiration. All three were dropped partway through this piece's work when
the operator reprioritized it as a secondary artifact (the engine's primary
target became general instrumental-motif generation, not this genre
specifically) and asked for the work in flight to be wrapped up rather than
expanded. Separately, another engine variant already added genuine physical
noise-excitation/pluck DSP (`dsp/bow-breath-voice.mjs`,
`dsp/karplus-strong.mjs`, both tested) during the same work session, which
made a second, cruder noise-transient specifically for this piece redundant.
This render's melodic layer therefore uses only the additive-partial timbre
above, not a physically modeled noise excitation. The guqin fixture's
invented note content was **not** used anywhere in this render's generation
-- it stayed illustrative/synthetic, as its own `source-note.md` requires.

## Honesty about the match to the actual reference genre

This is a best-effort technical match to the *researched genre
characteristics* (sparse texture, traditional-instrument-coded timbre, slow
harmonic movement), not a verified match to any specific reference audio --
nobody involved in producing this render has heard the reference tracks.

**Measured, not guessed:**
- Duration: 480.000s requested and actual.
- No clipping: peak 0.2237 (-13.0 dBFS); not silent: RMS 0.0361 (-28.9 dBFS).
- All samples finite.
- Voice-activity instrumentation (`voiceActivitySummary`, sampled every
  0.5s across the render): mean simultaneous voice count (pad bed + melody
  combined) 2.92; the track spends 16.4% of its duration at one or zero
  simultaneous voices. It is never at true silence (`fractionSilent = 0`)
  -- the low-`maxVoices` pad bed keeps 1-2 voices continuously sustained
  rather than dropping to nothing, so this reads as a persistent thin
  duo/trio drone with an intermittent foreground line, not literal silence
  between gestures. A separate automated comparison
  (`test/compose-sparse.test.mjs`, 4 seeds x 60s) confirms the sparse
  settings used here reliably produce a lower mean voice count and a higher
  low-activity fraction than the engine's default settings on the same
  seeds -- the sparsening is real and consistent, just less silence-heavy
  than "zen ambient" branding might suggest.

**Aesthetic guesses, not measured claims:** the pentatonic-mode choice,
`breathyFlute`/`pluckedString`'s actual perceptual closeness to a real
flute or plucked string, and whether the result reads as "zen ambient
soundscape" to a listener familiar with the reference genre.
