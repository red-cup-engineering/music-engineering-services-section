# Source note: `lounge-noir.wav`, `anticipation-riser.wav`, `celebration-fanfare.wav`, `sparkle-ornament.wav`, `guqin-echo.wav`

Five short renders exercising the arrangement/leitmotif/harmony/transitions
layer added alongside these files, generated by
`node scripts/render-demos.mjs` (reproducible; each preset's exact
seed/options live in `src/generative/demo-presets.mjs`, not restated here so
this note can't drift out of sync with the code).

- **`lounge-noir.wav`** (37.5s): a static-intensity (0.3) ambient bed --
  `arrangement.mjs`'s `bed` + a thin `pulse` stem only, A aeolian, nylon
  Karplus-Strong pulse, `chamber` reverb. Demonstrates the idle floor a game
  would sit at with no player activity.
- **`anticipation-riser.wav`** (25.5s): an intensity arc from 0.15 to 0.95
  (`intensityFromBreakpoints`) that activates every stem in turn as it
  climbs, plus a bar-quantized `transitions.mjs` riser (`scheduleRiser`)
  brightening the ornament stem's filter cutoff, resolving exactly on the
  final bar.
- **`celebration-fanfare.wav`** (21.5s): D Ionian/major, high held intensity
  (0.9), plus a motif-driven stinger (`scheduleStinger`) at the very first
  downbeat -- the piece's own leitmotif transposed up a fifth, layered on
  top of the arrangement without touching the bed/pulse/lead events already
  scheduled.
- **`sparkle-ornament.wav`** (25.5s): E major pentatonic, tuned so only the
  bed and a heavily-favored ornament stem are active at intensity 0.8 --
  exercises the ornament stem's density scaling in isolation.
- **`guqin-echo.wav`** (31.5s): the guqin corpus pipeline (`corpus.mjs`),
  D aeolian, `guqinAdjacent` Karplus-Strong preset used for pulse/lead/
  ornament. **The pitch contour is derived from the illustrative corpus
  fixture's real `string` field only** (see
  `data/corpus/guqin/source-note.md`) -- it is not a claim about the actual
  melodic content of *Meihua Sannong*, and no part of the corpus fixture's
  own already-invented note content (position/technique/pitch_interpretive)
  was used. See `src/generative/corpus.mjs`'s header comment for the exact
  honesty accounting.

All five passed the same finite/no-clipping/not-silent self-checks
`scripts/render-track.mjs` runs, plus a real-note-events-produced check
(`scripts/render-demos.mjs`); see the top-level README's "Arrangement /
adaptive layering" section for the worked floor-bed -> riser -> fanfare
example these renders illustrate.
